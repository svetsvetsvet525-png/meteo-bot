# Norilsk Aktirovka Bot ❄️

Telegram-бот, который присылает в чат класса информацию об **актировках в Норильске**
(отмена занятий из-за мороза и ветра), штормовые предупреждения и погоду.
Написан по мотивам школьного проекта [EDeev/npr_meteobot](https://github.com/EDeev/npr_meteobot)
(2022), но на современном стеке: **Python 3.11+, aiogram 3, SQLite, BeautifulSoup, httpx** —
без Selenium и без тяжёлых зависимостей.

## Что умеет

- 🔔 **Автоматическая рассылка** в чат(ы) класса при изменении сводки об актировках
  (проверка источников каждые 5 минут, настраивается);
- 🌘 Подхватывает и **вечерние объявления на завтра** — алерт придёт вечером, а не утром;
- 🎯 **Понимает, касается ли актировка вашего класса**: настраиваются район,
  смена и класс — при актировке приходит алерт «ВАС КАСАЕТСЯ», иначе — обычная сводка;
- 🏫 Поддержка **технических актировок** для конкретных школ (`/school 31`);
- 🌪 **Штормовые предупреждения** (ГО и ЧС Норильска + канал «Актировка Норильск»);
- 🌤 **Погода** в Норильске сейчас/сегодня/завтра (Open-Meteo, без API-ключа);
- ✅ Ежедневная сводка «актировок нет» (можно выключить командой `/digest`).

## Источники данных

| Приоритет | Источник | Что даёт |
|---|---|---|
| 1 | Официальный сайт `норильск.рф/weather` (раздел «Сообщения ГОиЧС») | Первоисточник бюллетеня. Сейчас домен нестабилен (сломан DNS) — бот пробует его раз в час и включит автоматически, когда сайт оживёт |
| 2 | Портал «Северный город» `sgnorilsk.ru/pogoda` | Официальный бюллетень: объявление об актировках + таблица по районам, предупреждения ГО и ЧС |
| 3 | Сайт администрации `norilsk-city.ru/meteo` | То же самое — но сервер нестабильный |
| 4 | Канал `@aktirovka_norilsk` (веб-версия `t.me/s/...`) | Актировки текстом + штормовые предупреждения (замолчал с июня 2026) |
| 5 | `meteonpr.ru` | Резерв: подключается, только если остальные молчат |
| — | Open-Meteo | Прогноз погоды для команды `/pogoda` |

Бот опрашивает источники по цепочке и берёт данные у более авторитетного
источника при расхождении. В командах (`/aktirovka`, `/storm`) нестабильные
сайты администрации пропускаются, если быстрый портал уже ответил.

> ⚠️ **Важно (осень 2026):** канал `@aktirovka_norilsk` замолчал после июня 2026 —
> администрация перевела оповещения в мессенджер MAX
> (`max.ru/channel_actirovkanorilsk`). Сайт администрации `norilsk-city.ru`
> нестабилен (то лежит, то отдаёт просроченный SSL-сертификат — для него есть
> `SITE_VERIFY_SSL=0`). Поэтому основным источником стал портал
> «Северный город», который перепечатывает тот же бюллетень и работает
> стабильно.
>
> Про MAX: прочитать канал администрации программно нельзя — веб-страница
> `max.ru` отдаёт только название и описание канала (без постов), а Bot API
> ([dev.max.ru](https://dev.max.ru)) позволяет читать канал только боту,
> добавленному администратором самого канала. Официальные зеркала
> объявлений: сайт норильск.рф (раздел «Сообщения ГОиЧС» — источник №1 в
> таблице), приложение «112 Красноярского края» и соцсети ВК/OK (доступ
> только для зарегистрированных). Подписаться на MAX-канал вручную можно
> по ссылке `max.ru/channel_actirovkanorilsk`.

## Быстрый старт

### 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) → команда `/newbot`;
2. Придумайте имя (например, «Актировки 7А») и username;
3. Скопируйте токен вида `1234567890:AA...`.

### 2. Запустите проект

```bash
git clone <ваш-репозиторий> aktirovka-bot   # или просто распакуйте папку
cd aktirovka-bot
python -m venv .venv
# Windows:
.venv\Scripts\pip install -r requirements.txt
# Linux/macOS:
.venv/bin/pip install -r requirements.txt
```

Создайте файл `.env` по образцу `.env.example`:

```ini
BOT_TOKEN=ваш_токен_от_BotFather
CHECK_INTERVAL=300
TZ_NAME=Asia/Krasnoyarsk
```

Проверка источников без запуска бота (не тратит токен):

```bash
.venv/bin/python smoke_test.py      # Linux
.venv\Scripts\python smoke_test.py  # Windows
```

Запуск:

```bash
.venv/bin/python -m bot     # Linux
.venv\Scripts\python -m bot # Windows
```

### 3. Добавьте в чат класса

1. Добавьте бота в чат класса (или в личку с собой для теста);
2. В чате напишите `/setup` и выберите: район → смену → класс;
3. По желанию: `/school 31`, `/digest` (вкл/выкл ежедневную сводку «актировок нет»).

> 💡 Если бота добавили в чат, `/setup` может выполнить любой участник —
> договоритесь в классе, кто настраивает.

## Команды

| Команда | Что делает |
|---|---|
| `/aktirovka` | Сводка об актировках на сегодня + касается ли ваш класс |
| `/pogoda` | Погода в Норильске (сейчас, сегодня, завтра) |
| `/storm` | Последнее штормовое предупреждение |
| `/setup` | Настроить район, смену и класс (шаги с кнопками) |
| `/school 31` | Номер вашей школы — для технических актировок (`/school 0` — сброс) |
| `/digest` | Вкл/выкл ежедневную сводку «актировок нет» |
| `/status` | Текущие настройки чата |
| `/id` | Узнать chat_id чата |
| `/help` | Список команд |

## Как выглядит рассылка

Когда сводка меняется, в чат приходит сообщение:

- если актировка **касается вашего класса** — алерт:

```
❄️❄️❄️ АКТИРОВКА! ❄️❄️❄️
7-й класс, 1-я смена, Талнах
⚠️ Занятия отменяются — актировка с 1 по 11 классы.

❄️ Актировки на 20.03.2026
1-я смена:
• Норильск (Центральный район): ✅ актировок нет
• Талнах: ⚠️ актировка с 1 по 11 классы
...
```

- если **не касается** и включён `/digest` — обычная сводка с пометкой
  «ваш класс — занятия по расписанию»;
- если актировок нет нигде — короткое «✅ Актировок нет» (раз в сутки,
  когда объявление появится в источниках).

## Деплой на VPS (Linux, systemd)

```bash
sudo adduser --system --group --home /opt/aktirovka-bot bot
sudo rsync -a ./aktirovka-bot/ /opt/aktirovka-bot/   # код проекта
cd /opt/aktirovka-bot
sudo -u bot python3 -m venv .venv
sudo -u bot .venv/bin/pip install -r requirements.txt
sudo -u bot cp .env.example .env && sudo -u bot nano .env   # вписать BOT_TOKEN
sudo chown -R bot:bot /opt/aktirovka-bot
```

Установите юнит `deploy/aktirovka-bot.service` (в нём указан путь `/opt/aktirovka-bot`):

```bash
sudo cp deploy/aktirovka-bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now aktirovka-bot
journalctl -u aktirovka-bot -f     # смотреть логи
```

## Как расширять

- **Новый источник данных** (например, MAX): создайте модуль в `bot/sources/`,
  который возвращает `list[Announcement]` (`bot/models.py`), и добавьте его
  вызов в `bot/watch.py::collect()`. Разбор текста уже готов — используйте
  `parse_announcement()` из `bot/sources/parsing.py`.
- **Перекрытие дорог / прочие новости**: в `channel.py` добавить фильтр
  по ключевым словам и отдельную рассылку в `watch.py` (по образцу `broadcast_storms`).
- **Прогноз вероятности актировки**: взять официальный «График определения
  погодных условий» (температура/ветер по классам) и сравнивать с Open-Meteo —
  модуль `weather.py` уже отдаёт нужные поля.
- **Несколько городов**: модель `Board` уже хранит районы — добавьте ключи
  в `DISTRICT_KEYS` (`bot/models.py`) и алиасы в `parsing.py`.

## Ограничения и заметки

- Объявление, где перечислено несколько районов с **разными** диапазонами классов
  («в Центральном с 1 по 4, в Талнахе с 1 по 11»), парсится по первому диапазону —
  в Норильске пока не встречалось, но имейте в виду.
- Сайт администрации может быть недоступен из-за границы РФ (гео-фильтр) —
  запускайте бота на VPS в России. Портал sgnorilsk.ru работает и из-за границы.
- Штормовые из бюллетеня sgnorilsk.ru не имеют времени публикации, поэтому
  приходят только по команде `/storm` (не рассылаются автоматически, чтобы
  не спамить повторяющимися предупреждениями). Штормовые из канала с метками
  времени рассылаются автоматически.
- Официальный «График определения погодных условий» (пороги мороза/ветра по
  классам) есть на сайтах школ, например у СШ №28:
  `sh28-norilsk-r04.gosweb.gosuslugi.ru/.../grafik-aktirovok/` — пригодится для
  фичи «прогноз вероятности актировки» (см. «Как расширять»).
- Первый запуск запоминает текущее состояние источников как базу — поэтому
  самое первое **новое** объявление придёт в чат сообщением (а не промолчит).
  Дальше бот реагирует только на изменения сводки.
- Если изменится вёрстка бюллетеня — правьте `bot/sources/sgnorilsk.py`;
  разбор формулировок (`parsing.py`) завязан только на текст объявлений,
  он устойчивее.
- Если бот работает из-за границы (например, VPS в Финляндии), а российские
  сайты режут зарубежный трафик — настройте туннель через домашний ПК
  в России: инструкция в `tunnel/README.md`, настройка через `RU_PROXY`.
  Tor и бесплатные VPN для этого не подходят (exit-ноды не в России).
