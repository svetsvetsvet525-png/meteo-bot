# Туннель: как дать финскому VPS российский IP для гео-блокированных сайтов

Гео-блокированные российские сайты (норильск.рф, norilsk-city.ru) не отвечают
из-за границы. Бесплатный и надёжный обход — использовать **российский IP,
который уже есть у вас**: домашний ПК в Норильске или старый Android-телефон.
Устройство держит SSH-туннель к VPS, бот ходит на запрещённые сайты
с вашего домашнего российского IP.

Tor не подходит (exit-ноды почти никогда не в России), бесплатные российские
VPN — нестабильны и небезопасны.

## Схема

```
бот на VPS (Финляндия)
   │  RU_PROXY=http://127.0.0.1:12080
   ▼
sshd на VPS  ◄──── ssh -R 12080 ... ────  устройство в Норильске (российский IP)
                                              │  rus_proxy.py (порт 8888)
                                              ▼
                                     норильск.рф / norilsk-city.ru
```

Туннель используется ТОЛЬКО для двух гео-блокированных сайтов (белый список
в `rus_proxy.py`). Telegram и sgnorilsk.ru бот по-прежнему ходит напрямую.

Достаточно ОДНОГО агента — телефона или ПК. Если туннель подняли дважды,
второй просто не сможет занять порт (и будет ретраиться безвредно).

## Вариант А (лучший): старый Android-телефон + Termux

Телефон включён в розетку 24/7, Wi-Fi дома (или мобильный интернет, трафик
~200 МБ/мес). Установка — три команды в Termux:

1. Установите [Termux](https://f-droid.org/packages/com.termux/) (с F-Droid,
   не Play Market) и, по желанию, **Termux:Boot** (тоже F-Droid).
2. В Termux:
   ```
   pkg install -y openssh
   scp root@<адрес-vps>:/root/norilsk-bot-tunnel/termux_setup.sh ~
   bash ~/termux_setup.sh root@<адрес-vps>
   ```
   (скрипт спросит пароль от VPS один раз — чтобы поставить SSH-ключ,
   дальше всё работает без пароля; лог: `tail -f ~/tunnel/agent.log`)
3. Отключите оптимизацию батареи для Termux: Настройки → Приложения →
   Termux → Батарея → «Без ограничений». Держите телефон на зарядке.

Разово с Windows закиньте папку туннеля на VPS:
```
scp -r tunnel root@<адрес-vps>:/root/norilsk-bot-tunnel
```

## Вариант Б: домашний ПК (Windows)

1. Убедитесь, что `ssh root@<адрес-vps> exit` проходит без вопросов.
2. Запустите (окно можно свернуть; для автозагрузки — ярлык в `shell:startup`):
   ```
   .\tunnel\start_tunnel.ps1 -VpsHost "root@<адрес-vps>"
   ```

## Настройка на VPS (одинаковая для обоих вариантов)

В `.env` бота добавьте одну строку:
```
RU_PROXY=http://127.0.0.1:12080
```
и перезапустите бота. В логе при успешном туннеле появится
`норильск.рф ответил: ...` вместо предупреждения о недоступности.

## Проверка

На VPS:
```
curl -x http://127.0.0.1:12080 -o /dev/null -w "%{http_code}\n" https://xn--h1aecgfmj1g.xn--p1ai/weather/
```
`200` — туннель работает; `403` — домен не в белом списке прокси;
`502`/`000` — DNS/сайт недоступен с российского IP (сайт лежит для всех).

Проверка прокси без сайта (прокси жив? туннель поднят?):
```
curl -x http://127.0.0.1:12080 -o /dev/null -w "%{http_code}\n" https://sgnorilsk.ru/pogoda/
```

## Безопасность

- Прокси слушает только `127.0.0.1` на устройстве и на VPS — в интернет
  не торчит.
- Белый список доменов защищает от использования туннеля как открытого прокси.
- sshd на VPS должен разрешать forwarding (`AllowTcpForwarding yes` —
  по умолчанию включено).
